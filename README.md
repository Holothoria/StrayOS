# StrayOS

A small learning operating system written in Rust with a custom bootloader. StrayOS is an experimental project created to learn low-level programming, explore OS structure, and push the limits of my hardware and skills.

## About

StrayOS is being developed as a personal learning project. It includes a custom bootloader that handles the transition from 16-bit to 32-bit mode, and a kernel written in Rust. The project focuses on learning and experimentation rather than production use.

## Features (work in progress)

- Custom bootloader that transitions from 16-bit to 32-bit
- Kernel written in Rust
- Early screen output and basic kernel initialization

## Status

Active development — currently in the early stages. The bootloader and 32-bit support are under active development.
